4. **修复 V 型转弯震荡 Bug：**
   - 修改 `transformGlobalPlan` 函数中的逻辑。不要因为全局路径暂时离开局部代价地图就停止迭代，应允许路径重新进入，以解决机器人在经过尖锐拐角后的前后震荡问题。
